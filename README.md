# 🎴 MD_Board — 游戏王 Master Duel 桌面统计工具

一款专为**游戏王 Master Duel 主播/玩家**设计的**桌面统计叠加工具**。  
手动录入每局数据，实时生成无边框统计面板，可直接放入直播画面。

---

## 核心功能

### 📺 四个窗口，各司其职

| 窗口 | 打开方式 | 用途 |
|------|----------|------|
| **显示窗口** | 自动启动 | 无边框透明叠加面板，显示胜率、先后手、硬币、最近10场等核心数据。放在直播画面角落。 |
| **控制面板** | 自动启动 | 录入对局、管理预设、导出/导入数据、配置循环面板。 |
| **详细统计窗口** | 控制面板 → 📊 | 全部维度数据卡片式分析（手坑、卡手、终场、突破、失误、T0、提丰、卡组统计、各卡组胜率趋势等）。标题栏「📝 .md」一键导出 Markdown 统计报告，含完整原始数据表（16列）和字段说明附录。 |
| **图表窗口** | 控制面板 → 📈 | 25 种可视化图表（饼图/柱状图/折线图/半环表盘），支持左右翻页导航。 |
| **循环显示面板** | 控制面板 → 🔄 | 始终置顶的循环展示窗口，可选 27 种统计项自动轮播。 |

### 📊 统计维度

**基础统计：** 总场次、胜/负/平/异常、胜率（>50%绿/<50%红动态标识）、先手/后手胜率、硬币统计、连胜/连败

**对局细节：**
- 吃手坑（自定义预设管理，支持增删手坑类型）**含先后手细分**
- 卡手原因（卡废件 / 卡同名牌 / 卡后手牌 / 互卡）**含先后手细分**
- 完全动不了次数 **含先后手细分**
- **各卡组卡手明细** — 统计面板和图表面板中按自用卡组展示卡手率及细分次数
- 先手终场质量（正常场 / 妥协场 / 没做出来 / 直接胜利 / 投降）
- 后手突破（成功 / 失败 / 投降 / 不需要）
- 连接异常（自己掉线 / 对手掉线 / 自己超时 / 对手超时）**含胜负自动锁定**
- 对局类型：普通 / 🔥晋级赛 / 💧保级赛（独立统计所有维度）

**高级统计：**
- 时间范围过滤（全部 / 一天 / 一整周 / 一整月 / 自定义），一天模式下可按具体日期过滤并显示「今天」标识，一整周/一整月可按周/月范围选择，自定义可输入任意起止日期，所有面板同步生效
- 跨日自动感知 — 录入对局跨日后自动刷新日期范围；日期选择器内提供 **↻ 手动刷新** 按钮，一键更新「今天」/本周/本月
- **各卡组胜率趋势** — 统计面板中按卡组分别绘制的累计胜率曲线（可勾选显示/隐藏）
- **硬币胜率趋势** — 统计面板/图表面板/轮播面板中的硬币正反累计胜率曲线（含50%对比线）
- **特定卡组胜率趋势** — 轮播面板和图表面板中可配置跟踪单个卡组的胜率趋势
- **硬币异常检测** — 统计面板/图表面板/轮播面板中检测连正/连反异常和正反偏斜（含异常率评分）
- 严重失误（频率 / 按卡组分布 / 失误时胜率）
- 对手 T0 动（频率 / 按对手卡组分布 / 被T0动时胜率）
- 吓跑对手（频率 / 按自用卡组分布 **含终场/突破细分**）
- 提丰趣味统计（被黑 vs 漂白次数）
- 抽干牌组统计
- 遇到大牌哥次数（含遭遇率、关联卡手参考、**先后手细分**）

**卡组分析：**
- 自用卡组胜率排行
- 对战卡组胜率排行（Top 10 图表）
- 自己卡组 vs 对手卡组 二维交叉胜率矩阵
- **各卡组胜率趋势** — 统计面板中每个卡组的累计胜率曲线，支持勾选显示/隐藏

**可视化图表（25 种）：**
胜负分布 · 先后手对比 · 手坑分布（**可自选手坑类型**） · 先手终场 · 后手突破 · 胜率趋势 · 硬币胜率趋势 · 自用卡组胜率 · 对战卡组胜率 · 特定卡组胜率趋势 · 连胜状态 · 硬币统计 · **硬币异常检测** · 卡手原因 · **完全动不了** · 严重失误 · 对手 T0 动 · 吓跑对手（**含终场/突破细分**） · 提丰统计 · 掉线统计 · 超时统计 · 遇到大牌哥（**含先后手细分**） · 概览 · 抽干牌组 · 晋级/保级赛

每张图表均配备详细数据面板，展示精确计数和比率进度条。

## 使用说明

### 录入对局

1. 在控制面板中按顺序选择：
   - **自己卡组**（支持预设管理）
   - **对手卡组**（支持预设管理）
   - **硬币**胜负
   - **先后手**
   - **结果**（胜 / 负 / 平局）
2. 勾选对局情况（手坑、卡手、掉线、超时、提丰、抽干牌组等折叠式菜单）
3. ⚡ 异常 — 独立 toggle，选中时隐藏所有对局情况，锁定胜负结果
4. 根据先后手选择终场情况或突破情况；双方都动不了时选择先动方/投降/其他
4. 点击 **提交** 或按 **Enter**

> 提交后自己卡组自动保留，方便连续使用同一卡组。

### 查看统计

- 📊 **详细统计窗口** — 全部维度数据卡片式展示
- 📈 **图表窗口** — 左右翻页浏览 25 种可视化图表
- 🔄 **循环显示面板** — 配置要循环的统计项后自动轮播

### 数据管理

- **预设卡组** — 分别管理对手卡组和自用卡组预设
- **导出 / 导入** — 备份和恢复所有对局数据（JSON 格式 / Markdown 统计报告）
  - 📄 **JSON 导出** — 完整数据备份，支持导入恢复
  - 📝 **.md 导出** — 详细统计面板中一键导出 Markdown 报告，含全部统计数据、算法说明及原始对局明细，可直接拖入 AI 进一步分析
- **重置** — 清空所有对局记录（预设卡组保留）

## 直播设置（B站直播姬 / OBS）

1. 启动 MD_Board
2. 在直播软件中添加 **窗口捕获** 来源
3. 选择 `MD Stats - 显示窗口` 进程
4. 裁剪窗口区域，只保留统计面板部分
5. （可选）调整大小和位置

## 数据存储

所有对局数据自动保存在系统临时目录（`%TEMP%/md-stats-data/stats.json`），使用 **AES-256-GCM** 自动加密存储。加密密钥嵌入文件自身，复制到任何机器都能直接解密，无需额外配置。

如需备份数据，请在控制面板使用「导出」功能导出明文 JSON；恢复时使用「导入」功能。

所有数据仅存储在本地，不上传任何服务器。

## 开发

### 从源码运行

```bash
git clone https://github.com/7starsseeker/MD_Board.git
cd MD_Board
npm install
npm start
```

> 便携版 exe 从 [Releases](https://github.com/7starsseeker/MD_Board/releases) 下载 `MD_Board_x.x.x_portable.exe`，双击运行即可。

### 测试

```bash
npm test
```

使用 Node.js 内置 `node:test` 运行，零外部依赖。覆盖核心统计函数（胜率计算、连胜/连败、硬币统计、手坑统计等）和 AES-256-GCM 加密模块。

### 打包

```bash
npm run pack
```

输出便携版 exe 到 `release/` 目录。
