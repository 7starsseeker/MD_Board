# 🎴 MD_Board — 游戏王 Master Duel 对局统计板

一款供游戏王 Master Duel 主播/玩家使用的**桌面统计叠加工具**。  
通过**手动录对局数据**，实时生成可放在直播画面中的**无边框统计面板**。

---

## 这是什么

MD_Board 是一个 Electron 桌面应用，包含两个窗口：

| 窗口 | 用途 |
|------|------|
| **显示窗口** | 无边框透明叠加面板，显示统计数据（胜率、先手/后手战绩、硬币胜率、最近10场等）。放在直播画面角落，不遮挡游戏主画面。 |
| **控制面板** | 每局打完后手动录入结果（胜负/平局/异常、先后手、硬币、对手卡组、终场情况、突破情况、手牌情况等）。 |

数据自动保存，重启不丢失。

---

## 适用场景

- 🎥 **直播游戏王 MD** — 显示窗口作为直播叠加层，实时展示对局统计
- 📊 **个人复盘** — 记录每局细节（卡组、手牌质量、G/陨石等），分析胜率趋势
- 🏆 **上分记录** — 跟踪先手/后手胜率、对特定卡组胜率，优化策略

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) v18 或更高版本（仅开发/重新打包时需要）
- Windows / macOS / Linux

### 快速启动（推荐）

下载 `release/MD_Board-win32-x64/` 目录，运行其中的 **MD_Board.exe** 即可。  
或双击项目目录下的 `start.bat`。

### 从源码运行

```bash
git clone https://github.com/7starsseeker/MD_Board.git
cd MD_Board
npm install
npm start
```

### 重新打包成 exe

```bash
npm run pack
```

打包后的 exe 位于 `release/MD_Board-win32-x64/MD_Board.exe`。

### 直播设置（B站直播姬 / OBS）

1. 启动 MD_Board
2. 在直播软件中添加**窗口捕获**来源
3. 选择 `MD Stats - 显示窗口` 进程
4. 裁剪窗口区域，只保留统计面板部分
5. （可选）调整窗口大小和位置

## 使用说明

### 录入对局

1. 在控制面板中按顺序选择：
   - **硬币**胜负
   - **先后手**
   - **结果**（胜 / 负 / 平局 / 异常）
   - **对手卡组**（支持预设管理）
2. 勾选对局情况（吃G、卡手、双方动不了等）
3. 根据先后手选择终场情况或突破情况
4. 点击**提交**或按 **Enter**

### 数据管理

- **预设卡组** — 点击「管理预设」添加常用对手卡组名称，快速填入
- **导出 / 导入** — 备份和恢复所有对局数据
- **重置** — 清空对局记录，预设卡组保留

## 数据隐私

所有数据仅存储在本地计算机上，不上传任何服务器。  
数据文件位于程序目录下的 `data/stats.json`，可随程序文件夹一起移动，实现绿色便携。
