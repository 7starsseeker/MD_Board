# 🎴 MD_Board — 游戏王 Master Duel 对局统计板

一款供游戏王 Master Duel 主播/玩家使用的**桌面统计叠加工具**。  
通过**手动录对局数据**，实时生成可放在直播画面中的**无边框统计面板**。

---

## 这是什么

MD_Board 是一个 Electron 桌面应用，包含三个窗口：

| 窗口 | 用途 |
|------|------|
| **显示窗口** | 无边框透明叠加面板，显示统计数据（胜率、先手/后手战绩、硬币胜率、最近10场等）。放在直播画面角落，不遮挡游戏主画面。 |
| **控制面板** | 每局打完后手动录入结果。 |
| **详细统计窗口** | 展示全部维度的数据分析（手坑统计、先手终场质量、后手突破率、卡手统计、超时/掉线、提丰趣味统计、交叉对阵统计等）。 |

数据自动保存，重启不丢失。

---

## 适用场景

- 🎥 **直播游戏王 MD** — 显示窗口作为直播叠加层，实时展示对局统计
- 📊 **个人复盘** — 记录每局细节（卡组、手牌质量、G/陨石/大宇宙人等），分析胜率趋势
- 🏆 **上分记录** — 跟踪先手/后手胜率、对特定卡组胜率，优化策略

---

## v2.0 新功能

- **独立详细统计窗口** — 点击控制面板「📊 详细统计」打开，涵盖全部维度的数据分析
- **自用卡组记录** — 每局记录自己使用的卡组，按自己卡组维度统计胜率
- **全面统计覆盖** — 吃手坑率、卡手率、互卡、掉线/超时、先手终场质量、后手突破率、OTK率、大牌哥等全部纳入统计
- **二维交叉对阵统计** — 自己卡组 vs 对手卡组 的胜率矩阵
- **提丰趣味统计** — 记录提丰出场情况，统计「提丰被黑/漂白」次数
- **出牌失误统计** — 记录失误次数，按卡组交叉分析，占总局百分比
- **对手T0动统计** — 先手时记录对手 T0 干扰，按对手卡组分布
- **对局情况两列布局** — 节省纵向空间，更紧凑
- **增强的数据保存** — 源码模式每次修改自动同步到项目 `data/` 目录；便携版 exe 首次使用弹窗询问，保存后自动进入持久模式

完整更新日志见 [CHANGELOG.md](./CHANGELOG.md)。

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) v18 或更高版本（仅开发/重新打包时需要）
- Windows / macOS / Linux

### 从源码运行

```bash
git clone https://github.com/7starsseeker/MD_Board.git
cd MD_Board
npm install
npm start
```

> 如需便携版 exe，请从 [Releases](https://github.com/7starsseeker/MD_Board/releases) 页面下载。

## 数据存储

### 源码模式

数据在每次修改时自动保存到项目目录下的 `data/` 文件夹，关闭时无需额外操作。重启自动加载。

### 便携版 exe

- **首次使用**（无 `data/` 目录）：退出时弹窗询问是否保存到 exe 同级目录
- **已有 `data/` 目录**：每次修改自动保存，退出无弹窗

所有数据仅存储在本地计算机，不上传任何服务器。

## 使用说明

### 录入对局

1. 在控制面板中按顺序选择：
   - **自己卡组**（支持预设管理）
   - **对手卡组**（支持预设管理）
   - **硬币**胜负
   - **先后手**
   - **结果**（胜 / 负 / 平局 / 异常）
2. 勾选对局情况（吃G、卡手、掉线、提丰、失误等）
3. 根据先后手选择终场情况或突破情况
4. 点击**提交**或按 **Enter**

### 查看详细统计

- 点击控制面板标题栏的 **「📊 详细统计」** 按钮，弹出独立统计窗口
- 包含：概览大数字、先后手对比、硬币统计、吃手坑统计、手牌状态、失误统计、对手T0动、先手终场质量、后手突破、连接异常（掉线/超时分卡组）、提丰趣味统计、自用卡组统计、对战卡组统计、对阵交叉统计

### 数据管理

- **预设卡组** — 分别管理对手卡组和自用卡组的预设，快速填入
- **导出 / 导入** — 备份和恢复所有对局数据
- **重置** — 清空对局记录，预设卡组保留
- **自己卡组沿用** — 提交一局后自己卡组自动保留，不需重复选择

## 直播设置（B站直播姬 / OBS）

1. 启动 MD_Board
2. 在直播软件中添加**窗口捕获**来源
3. 选择 `MD Stats - 显示窗口` 进程
4. 裁剪窗口区域，只保留统计面板部分
5. （可选）调整窗口大小和位置
