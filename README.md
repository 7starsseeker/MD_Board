# 🎴 MD_Board — 游戏王 Master Duel 桌面统计工具

一款专为**游戏王 Master Duel 主播/玩家**设计的**桌面统计叠加工具**。  
手动录入每局数据，实时生成无边框统计面板，可直接放入直播画面。

---

## 核心功能

### 📺 四个窗口，各司其职

| 窗口 | 打开方式 | 用途 |
|------|----------|------|
| **显示窗口** | 自动启动 | 无边框透明叠加面板，显示胜率、先后手、硬币、最近10场等核心数据。放在直播画面角落。 |
| **控制面板** | 自动启动 | 录入对局、管理预设、导出/导入数据、配置循环面板。 |
| **详细统计窗口** | 控制面板 → 📊 | 全部维度数据卡片式分析（手坑、卡手、终场、突破、失误、T0、提丰、卡组统计、各卡组胜率趋势等）。 |
| **图表窗口** | 控制面板 → 📈 | 23 种可视化图表（饼图/柱状图/折线图/半环表盘），支持左右翻页导航。 |
| **循环显示面板** | 控制面板 → 🔄 | 始终置顶的循环展示窗口，可选 26 种统计项自动轮播。 |

### 📊 统计维度

**基础统计：** 总场次、胜/负/平/异常、胜率、先手/后手胜率、硬币统计、连胜/连败

**对局细节：**
- 吃手坑（增殖的G / 鸟G / 水母G / 锁鸟 / 陨石 / 大宇宙人 / 其他）
- 卡手原因（卡废件 / 卡同名牌 / 卡后手牌）
- 被发牌员制裁（完全动不了 / 互卡）
- 先手终场质量（正常场 / 妥协场 / 没做出来 / 投降）
- 后手突破（成功 / 失败 / 投降 / 不需要）
- 连接异常（自己掉线 / 对手掉线 / 自己超时 / 对手超时）
- 对局类型：普通 / 🔥晋级赛 / 💧保级赛（独立统计所有维度）

**高级统计：**
- 时间范围过滤（全部 / 一天 / 一整周 / 一整月 / 自定义），一天模式下可按具体日期过滤，一整周/一整月可按周/月范围选择，自定义可输入任意起止日期，所有面板同步生效
- **各卡组胜率趋势** — 统计面板中按卡组分别绘制的累计胜率曲线（可勾选显示/隐藏）
- **硬币胜率趋势** — 统计面板/图表面板/轮播面板中的硬币正反累计胜率曲线（含50%对比线）
- **特定卡组胜率趋势** — 轮播面板和图表面板中可配置跟踪单个卡组的胜率趋势
- 严重失误（频率 / 按卡组分布 / 失误时胜率）
- 对手 T0 动（频率 / 按对手卡组分布 / 被T0动时胜率）
- 吓跑对手（频率 / 按自用卡组分布）
- 提丰趣味统计（被黑 vs 漂白次数）
- 抽干牌组统计
- 遇到大牌哥次数（含遭遇率、关联卡手参考）

**卡组分析：**
- 自用卡组胜率排行
- 对战卡组胜率排行（Top 10 图表）
- 自己卡组 vs 对手卡组 二维交叉胜率矩阵
- **各卡组胜率趋势** — 统计面板中每个卡组的累计胜率曲线，支持勾选显示/隐藏

**可视化图表（23 种）：**
胜负分布 · 先后手对比 · 手坑分布 · 先手终场 · 后手突破 · 胜率趋势 · 硬币胜率趋势 · 自用卡组胜率 · 对战卡组胜率 · 特定卡组胜率趋势 · 连胜状态 · 硬币统计 · 卡手原因 · 被发牌员制裁 · 严重失误 · 对手 T0 动 · 吓跑对手 · 提丰统计 · 掉线统计 · 超时统计 · 遇到大牌哥 · 概览 · 抽干牌组 · 晋级/保级赛

每张图表均配备详细数据面板，展示精确计数和比率进度条。

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) v18 或更高
- Windows / macOS / Linux

### 从源码运行

```bash
git clone https://github.com/7starsseeker/MD_Board.git
cd MD_Board
npm install
npm start
```

### 使用便携版 exe

从 [Releases](https://github.com/7starsseeker/MD_Board/releases) 页面下载 `MD_Board_x.x.x_portable.exe`，双击运行即可。

## 使用说明

### 录入对局

1. 在控制面板中按顺序选择：
   - **自己卡组**（支持预设管理）
   - **对手卡组**（支持预设管理）
   - **硬币**胜负
   - **先后手**
   - **结果**（胜 / 负 / 平局 / 异常）
2. 勾选对局情况（吃G、卡手、掉线、提丰、失误等）
3. 根据先后手选择终场情况或突破情况
4. 点击 **提交** 或按 **Enter**

> 提交后自己卡组自动保留，方便连续使用同一卡组。

### 查看统计

- 📊 **详细统计窗口** — 全部维度数据卡片式展示
- 📈 **图表窗口** — 左右翻页浏览 18 种可视化图表
- 🔄 **循环显示面板** — 配置要循环的统计项后自动轮播

### 数据管理

- **预设卡组** — 分别管理对手卡组和自用卡组预设
- **导出 / 导入** — 备份和恢复所有对局数据（JSON 格式）
- **重置** — 清空所有对局记录（预设卡组保留）

---

## 直播设置（B站直播姬 / OBS）

1. 启动 MD_Board
2. 在直播软件中添加 **窗口捕获** 来源
3. 选择 `MD Stats - 显示窗口` 进程
4. 裁剪窗口区域，只保留统计面板部分
5. （可选）调整大小和位置

---

## 数据存储

所有对局数据自动保存在系统临时目录（`%TEMP%/md-stats-data/stats.json`），每次修改自动保存，重启自动加载。

如需备份数据，请在控制面板使用「导出」功能导出 JSON；恢复时使用「导入」功能。

所有数据仅存储在本地，不上传任何服务器。
